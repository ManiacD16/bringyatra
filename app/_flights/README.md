# BOOKINGS (temporarily hidden)

The `_flights`, `_buses` and `_hotels` folders are the Flight, Bus and Hotel booking pages.
Next.js ignores folders that start with `_`, so these pages are currently **not built or reachable**.

To bring them back, rename the folders:

    app/_flights  ->  app/flights
    app/_buses    ->  app/buses
    app/_hotels   ->  app/hotels

Then search the project for `BOOKINGS (temporarily hidden)` to restore the related links and sections.
